# Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open command palette / search |
| `Ctrl + I` | Go to Import page |
| `Ctrl + T` | Go to Transactions page |
| `Ctrl + F` | Go to Finances page |
| `Ctrl + R` | Go to Rules page |
| `Esc` | Close modal / deselect |

> Keyboard shortcuts are planned but may not all be implemented yet. Check the app for current support.
